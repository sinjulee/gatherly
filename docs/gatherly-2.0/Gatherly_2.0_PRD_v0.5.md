## 1. 제품 정의

Gatherly는 **특정 사업이나 산업에 종속되지 않는 범용 전시회·출장·현장조사 및 AI 보고서 서비스**다. 현장에서 검색/텍스트 확인보다 듣기·녹음·촬영·짧은 메모를 중심으로 조사하고, 행사 종료 후 사용자가 정한 분석 관점에 따라 자료를 검토·분석·보고서화한다. 탄소중립 플랫폼은 *가능한 개인 활용 사례 중 하나*일 뿐 서비스 목적을 한정하지 않는다.

### 핵심 가치
1. **현장 음성 중심:** 이어폰 안내 → 부스 선택 → 원터치 수집.
2. **지도 중심 탐색:** 제목·여백을 제거한 실제 부스배치도를 스크롤하여 위치를 찾고 **부스를 직접 눌러 기업 카드 확인**.
3. **개인 데이터 소유:** 개인 조사 기록은 사용자 Google Sheets, 원본 미디어는 사용자 Drive, 개인 보고서는 사용자 Docs/Drive.
4. **공식 공통 지식:** Gatherly가 전체 사용자에게 공유할 전시회/기업/승인된 AI 분석만 Supabase DB에 제공.
5. **결과물 중심 + 지속 가능한 운영:** 기존 AI 보고서 생성·AI 수정 요청·직접 편집·Google Docs 내보내기를 주요 **프리미엄 기능**으로 유지하며, 출시 초기에는 제한적인 무료 체험권으로 검증한다.
6. **공개 서비스 지향:** 웹 배포 후 외부 베타 사용자를 모집하고 피드백을 수집한다. 기본 현장조사/개인 자료 관리는 무료로 유지한다.

## 2. 검증된 사용자 문제와 목적
- 부산 벡스코 현장에서 이동 중 복잡한 기업 목록을 검색하고 긴 글을 읽는 것이 어려웠음.
- 현장 설명을 놓치지 않으면서 사진·음성·짧은 텍스트를 같은 기업에 기록해야 함.
- 지도에서 부스를 찾은 직후 앱에서 기업을 다시 검색하는 이중 작업을 제거해야 함.
- 스마트폰에서는 전체 지도 축소 표시만으로 부스번호가 읽히지 않으므로 **가로·세로 스크롤(팬)할 수 있는 확대 원본 지도**가 필요함.
- 조사 후 사용 목적에 맞는 보고서를 작성할 때 원본 근거, 공식 출처, AI 해석을 구분해야 함.

## 3. 대상 사용자 / 환경
- 전시회 방문자, 바이어, 마케팅/기획 담당자, 연구자, 창업자, 학생, 현장 조사팀 등.
- iPhone Safari/PWA 우선, Android Chrome 및 데스크톱 브라우저 확장.
- 한 손 조작, 블루투스 이어폰, 불규칙한 통신, 짧은 체류, 정보 입력 중 이동/통화 상황 고려.
- 사업 운영자는 출처 확인·데이터 품질 검토·공식 콘텐츠 승인·사용자 피드백을 담당.

## 4. 2026 ESG 친환경대전 실증 시나리오
1. **사전 수집:** 관리자가 공식 참가기업 디렉토리 URL을 등록하고, 수집 가능 범위 및 재사용 조건을 검토한다. 목록·상세 페이지를 시험 추출한 후 공식 전시사 기본 정보를 임시 저장/검수하고, 승인된 데이터를 Supabase 공통 카탈로그에 발행한다.
2. **지도 준비:** 운영자가 사용자 제공 부스배치도 원본에서 제목과 외부 공백을 제외한 **지도 본문 이미지**를 등록한다. 지도상의 개별 부스 영역에 부스번호·출전사 ID를 수동/반자동 매핑하고 검증한다.
3. **접속:** 사용자는 Google 로그인(Supabase Auth) 후 Google Drive/Sheets에 대한 별도 접근 동의 및 본인 저장소 구성을 수행한다.
4. **탐색:** 모바일에서 스크롤 가능한 부스배치도를 위·아래·좌·우로 탐색하거나 기업명/부스번호 검색으로 해당 부스로 이동한다.
5. **부스 선택:** 지도 위 해당 위치를 탭하면 **바로 지도 아래** 선택 기업의 정보 카드가 표시되고, 위치가 강조된다.
6. **도슨트:** 기업명 옆 **스피커** 아이콘으로 사전 생성된 짧은 한국어 소개를 이어폰으로 듣는다.
7. **자료 수집:** 기업명 옆 **카메라** 아이콘으로 사진을 찍거나 여러 장 선택한다. **마이크** 아이콘으로 설명을 녹음하며, 녹음 전 동의 고지를 확인한다.
8. **메모:** 마이크 **바로 옆 대문자 A 아이콘**을 탭하면 텍스트 메모 입력창(모바일 바텀시트)이 뜬다. 취소/저장 동작을 지원한다.
9. **저장:** 모든 개인 입력은 IndexedDB에 먼저 임시 보관한 뒤 파일은 본인 Google Drive, 방문/메모/파일 참조는 본인 Google Sheets로 안전하게 동기화한다.
10. **정리·보고:** 현장 자료를 기업별로 정리한다. **새로운 AI 보고서 생성·AI 수정 요청은 서버에서 이용권을 확인한 뒤** 사용자가 지정한 분석 목적에 따라 수행하며, 초안→수정 요청→직접 편집→Google Docs 내보내기를 지원한다. 무료 현장조사는 이용권과 관계없이 유지한다.

### 5.1 모바일 부스배치도 UX — 필수
- **원본 이미지 사용:** 제공된 부스배치도 이미지에서 상단 `부스배치도` 제목, 문서 상·하단 외부 공백, 불필요한 여백은 제거한다. 별도의 AI 재그림을 **실제 지도 데이터로 사용하지 않는다**. 이번 사용자 제공 두 번째 이미지는 제목이 제거된 지도 참고본이다.
- **지도의 고유 가로세로 비율 유지:** 스마트폰 너비에 맞춰 전체를 지나치게 축소하지 않는다. **고정 높이/반응형 뷰포트** 안에 지도를 확대 표시하여 양축 스크롤로 살펴본다.
- **스크롤 동작:** 손가락으로 상·하·좌·우 이동; 가로·세로 스크롤 가능함을 처음에 안내. 실제 iOS에서 네이티브 스크롤바는 자동 숨김될 수 있어 보조 방향 표시/미니맵/힌트를 검토한다. 데스크톱은 스크롤바와 휠/트랙패드 지원.
- **터치 선택:** 위치별 투명 클릭 영역을 선택하면 지도에 해당 영역 강조, **배치도 바로 아래** 기업정보 표시; 스크롤 후에도 선택 영역이 부스와 일치해야 한다.
- **선택 결과:** 기업명(굵게), 부스번호 배지, 분류, 기업·브랜드 및 출품 내용 핵심 요약, 공식 출처 링크, AI 한 줄 요약(승인된 경우), 자료 저장 상태.
- **매핑 없는 부스:** 잘못된 기업을 표시하지 않으며 `기업정보 확인 중` / `해당 부스 미등록` 안내와 기업 검색 또는 운영자 제보 기능 제공.
- **접근성:** 지도만으로 사용 불가한 환경을 대비해 텍스트 기반 기업·부스번호 검색과 목록을 병행한다.

### 5.2 기업명 옆 기능 아이콘 UI — 필수

| 순서 | 표시 | 버튼 이름 | 누른 뒤 실제 동작 | 저장 위치 |
|---:|---|---|---|---|
| 1 | **스피커** (`volume-2`) | 도슨트 해설 | 기업 소개 음성 재생·일시정지·재시작, 대본 대체 표시 | 승인된 안내/캐시는 Gatherly 운영 저장소 |
| 2 | **카메라** (`camera`) | 사진 자료 수집 | 모바일 촬영 또는 갤러리에서 다중 선택 후 미리보기/큐 추가 | 기기 → 개인 Drive, 메타데이터 개인 Sheets |
| 3 | **마이크** (`mic`) | 음성 자료 수집 | 녹음 동의 안내 → 시작/중지/타이머 → 미리듣기/저장 | 기기 → 개인 Drive, 메타데이터 개인 Sheets |
| 4 | **A** (`A` 문자) | 메모 기록 | **메모 입력창 호출** → 작성/취소/저장 | 기기 → 개인 Sheets의 notes 탭 |

- 큰 버튼(최소 44×44 CSS px), 그림+접근성 이름, 조작 후 명확한 상태 피드백을 제공한다.
- **정렬:** 기업명 오른쪽에 스피커→카메라→마이크→A 순서. 좁은 화면에서는 **같은 기업정보 카드 안에서 줄 바꿈**하되 순서를 유지한다.
- **메모 입력창:** 모바일 바텀시트/모달, 제목 `메모 기록`, 텍스트 영역, `취소`·`저장`, 닫기, 최초 500자 권장 한도(설정 변경 가능), 기존 메모 수정/재저장 지원. 키보드가 저장 버튼을 가리지 않게 처리한다.
- 메모 내용은 다른 부스에 잘못 연결되지 않도록 현재 `exhibitor_id`·`field_day_id`를 고정하며 저장 중 기업 선택이 변경되어도 일관성을 유지한다.
- TTS와 마이크 녹음은 기본적으로 동시에 켜지지 않으며 녹음 시작 시 재생을 멈춘다.

## 6. 참가기업 디렉토리 수집 및 공용 DB 활용 — 신규 핵심 기능

### 6.1 데이터 원천과 확인 사실
- 2026 대한민국 ESG 친환경대전 공개 참가기업 디렉토리: `https://www.k-eco.or.kr/home/v4.php?s=34`
- 개별 상세 예시: `https://www.k-eco.or.kr/home/v4_view.php?idx=44&s=34` (자원순환보증금관리센터, 부스 N-101)
- **2026-10-16 조회 시 웹사이트 표시 건수 239개사 / 목록 6페이지.** 이는 *사이트 표시 값*으로 고정 건수나 수집 완료 건수가 아니다. 행사 전 변동 가능.
- 목록 페이지에는 기업명·브랜드·카테고리·전시품목 요약이 표시되고, 상세 페이지에는 국/영문 기업명·브랜드·부스번호·주소·참가 부문·전시품목·국/영문 회사 소개·홈페이지/SNS·프로그램 정보·로고 URL 등이 보일 수 있다. **항목은 기업별로 누락 가능**.
- 목록 페이지의 `startPage` 쿼리를 이용한 페이지 이동 및 상세 페이지 `idx` 쿼리 방식이 관찰되었으나 실제 전량 수집 전 파서 검증 필요. 정적 HTML 추출을 우선하고 동적 브라우저 방식은 필요할 때만 사용.

### 6.2 관리자 수집기(Exhibitor Directory Importer)
1. **원천 등록:** 행사 ID, 공식 URL, 수집 범위, 담당자, 출처 및 사용 허용/확인 상태 입력.
2. **소량 PoC:** 목록 일부와 **상세 5개 기업**을 먼저 가져와 데이터 필드 추출·고유 ID·언어·HTML 줄바꿈·로고 링크를 검증.
3. **수집 전 권한 확인:** 공식 엑셀/CSV 제공 가능 여부와 공개 서비스 재게시 조건을 주최 측에 확인. robots/접근 제한/약관/저작권을 검토하고 요청 속도 제한 및 오류 중단 조건 설정. `robots.txt` 미확인은 허용의 증거가 아니다.
4. **전체 목록/상세 추출:** 페이징 탐색, 상세 URL 추출, 원본 필드 정규화, 로그 기록. 기하급수적 재시도나 요청 폭주는 금지.
5. **스테이징:** 추출 결과는 **공개 테이블에 즉시 게시하지 않고** 관리자 검토 대기 상태로 저장.
6. **검증:** 원본 URL 확인, 부스번호 충돌, 중복 기업, 누락값, 한영문 혼동, 수집 실패, 원본 변경 비교.
7. **공개 승인:** 관리자 검토 후 공개 가능한 범위만 Supabase 공식 카탈로그에 반영; 원문 전체/이미지 재게시 권한이 없는 경우 짧은 사실정보·요약과 원문 링크 중심으로 축소.
8. **갱신:** 변경 감지·미리보기·선택적 승인/발행; 수정 전 버전 및 롤백 근거 유지.

### 6.4 DB 활용
- `exhibitions`(공식 행사), `companies`(기업 정체성), `exhibitors`(행사별 참가·부스정보)를 분리.
- `directory_sources`/`import_runs`/`staging_exhibitors`로 출처·실행·대기 자료 관리.
- `booth_map_assets`/`booth_hotspots`로 행사별 공식 지도와 누를 수 있는 위치를 분리.
- `ai_company_briefings`/`ai_evidence`로 출처 기반 대본·음성 캐시·승인 상태 보존.
- 동일 기업의 **전시회별 부스**는 다를 수 있으며, 이름으로만 자동 병합하지 않는다.
- 사용자 개인 녹음/메모를 허락 없이 공용 DB나 AI 공개 분석에 복제하지 않는다.
- 다른 전시회에도 재사용할 수 있는 입력 어댑터를 설계하되 각 사이트별 추출 규칙은 별도 구현/검증한다.

## 7. 저장소/인증 아키텍처 — v0.3 결정 유지
| 데이터 | 저장/관리 |
|---|---|
| Google 로그인·세션 | Supabase Auth |
| 공식 행사·기업·검수된 공개 AI 분석·부스매핑·Importer 기록 | Supabase PostgreSQL |
| 개인 현장 방문·메모·관심도·파일 참조·전사·개인 AI 인사이트·보고서 목록 | **사용자 본인 Google Sheets** |
| 개인 사진·녹음·영상·보고서 근거 스냅샷 | **사용자 본인 Google Drive** |
| 보고서 본문·수정 결과 | 사용자 본인 Google Drive/Docs |
| 미전송 원본·동기화 대기 | IndexedDB / 기기 임시 저장 |
| 최소 운영 메타데이터·사용량·피드백·역할·체험권·쿠폰 사용 이력·보고서 사용량 집계 | Supabase (RLS 및 별도 접근제어; 보고서 본문/개인 수집자료 제외) |

Google 로그인과 Drive/Sheets 파일 접근은 권한 단계를 분리하며 OAuth 승인/철회/재연결을 다룬다. 서버 측 토큰은 암호화·보호하고 파일·개인 데이터는 사용자 간 격리한다. 앱이 생성·연결한 파일 중심의 최소 권한(`drive.file` 등)으로 설계한다.

## 8. 현장 자료 수집·동기화
- **로컬 선저장 → Drive 원본 업로드 → Sheets 메타데이터 확정**의 2단계 동기화.
- 각각 사진·녹음·메모는 기업/전시회 ID, 고유 ID, 로컬 시각을 보유. 오프라인에서도 캡처/임시 저장을 우선.
- 상태: 로컬 대기, 업로드 중, Drive 업로드 완료/Sheets 반영 대기, 동기화 완료, 재시도, 인증 재연결 필요, 충돌.
- Sheets 수동 편집·행 이동을 감지할 수 있게 행 번호가 아니라 UUID 기반.
- Drive 성공, Sheets 실패 시 파일 재업로드 없이 이어서 확정. 사용자에게 실패 건수와 재시도 안내.
- 로컬 브라우저 저장소는 용량·OS 정책에 따라 사라질 수 있으므로 절대적 무손실을 보장하지 않으며, 가능하면 촬영 후 빠른 동기화를 권장.

## 9. AI 도슨트 기능
- 공개 원천과 검수된 기업 정보로 **한국어 20~40초** 브리핑 스크립트 생성; 기업 개요/전시품목/주요 특징/확인 질문 등.
- Gemini TTS를 통해 사전 생성·캐시된 음성을 제공하며, 스피커 버튼으로 재생/일시정지/다시 듣기.
- 도슨트 콘텐츠에는 `source_url`, 생성일, 대본 버전, 검토 여부를 기록. 자료가 없는 기업은 생성 불가/텍스트 대체를 표시.
- 행사 전 사전 캐싱 우선; 현장 네트워크 끊김·TTS 장애에서도 사진/녹음/메모는 별개로 사용 가능.
- 개인 녹음의 전사·AI 분석은 개인 정보이며 공개 승인된 공식 콘텐츠와 분리.

## 10. AI 보고서 — 기존 기능 유지 + 프리미엄 이용권 적용
- 사용자는 분석 방향을 자유롭게 입력한다(시장성, 제품 전략, 기술성, 마케팅, 경쟁사, 산업 동향 등). 특정 산업 또는 사업 목적에 고정하지 않음.
- 방문 기업/사진/메모/음성 원본/전사/공식 출처를 **선택해 근거로 연결**하여 관점별 다른 보고서를 생성.
- 외부 조사는 신뢰도 및 출처·확인 날짜 표시; 원본 사실/추가 조사/AI 판단·추론 분리.
- 가독성 높은 표·이미지·핵심 요약, 보고서 버전·인용·근거 추적 제공.
- AI **초안 생성 → 사용자 수정 요청 → 재생성/버전 보존**, 직접 텍스트 수정, Google Docs 생성·편집 지원.
- 보고서 생성 시 사용자 소유 Drive에 사용 자료의 입력 스냅샷 저장; 개인 본문은 공용 Supabase DB에 넣지 않음.
- **보고서 생성·AI 재생성은 프리미엄 권한 확인 후에만 수행한다.** 다만 이용 기간이 끝나도 이미 생성된 Google Docs는 사용자 소유로 남아 열람·직접 편집·다운로드할 수 있다.
- 기존 미구현 기능을 구현 완료로 표기하지 않으며, 요구사항·검증 계획에서 제외하지 않는다.

## 11. 사용자 유형·AI 보고서 체험권·프리미엄 운영 정책 — v0.5 신규

### 11.1 사용자 유형 — 정확히 4종

| 화면상 사용자 유형 | 판단 기준 | 현장조사·개인 저장소 | 신규 AI 보고서 작성 | 비고 |
|---|---|---|---|---|
| **일반 무료 사용자** | 가입 직후 또는 체험/프리미엄 권한 없음 | 가능 | 불가 | 이전에 생성한 본인 보고서는 계속 조회·직접 편집 가능 |
| **무료 체험 사용자** | 유효한 **기간형 또는 1회형 체험권** 보유 | 가능 | 체험권의 기간·횟수·정책 내 가능 | 만료/소진 시 자동으로 일반 무료 사용자로 표시 |
| **프리미엄 사용자** | 유효한 프리미엄 이용권 보유 | 가능 | 해당 프리미엄 상품의 사용량·비용 정책 내 가능 | 결제 연동은 후속 릴리스, 관리자 수동 지급/테스트 허용 |
| **관리자** | 서버 통제된 관리자 역할 | 가능 | 별도 운영 정책/테스트 이용권에 따라 가능 | DB 게시·수집기·쿠폰·사용량 관리. 일반 사용자 승격 불가 |

- 이 4가지만 사용자 분류로 사용한다. 기존에 제안한 별도의 조직/기관 목적 사용자 역할은 폐기한다.
- **역할과 상품/체험권은 분리**한다. 실제 구현은 관리자 여부(안전한 `role`/`app_metadata` 또는 관리자 테이블) + 이용권(`entitlement`)으로 계산한 **표시용 4개 상태**를 제공한다. 영구적인 `free_trial` 역할을 직접 저장하지 않아도 된다.
- 우선순위는 `관리자 > 프리미엄 > 무료 체험 > 일반 무료`. 표시 상태가 바뀌어도 방문·사진·녹음·메모와 개인 Sheets/Drive 데이터는 그대로 유지한다.
- 초기 비용 관리와 보안을 위해 관리자가 다른 사용자의 Google Drive/Sheets에 자동 접근하는 권한은 부여하지 않는다.

### 11.2 체험권 2종

**A. 기간형 무료 체험권**
- 쿠폰 사용 시점 또는 관리자가 지정한 활성화 시점부터 정해진 기간 동안 보고서 생성 허용. 관리자는 `duration_days`, 활성화 시점, 만료 시각, 기간 내 **최대 신규 보고서 수**와 AI 수정 한도(필요 시)를 설정한다.
- 예시: 등록 후 7일, 신규 보고서 최대 3건. 예시는 확정 요금제가 아니며 관리 화면에서 변경 가능.
- 기간 만료 또는 설정된 횟수 소진 중 먼저 도달한 조건을 적용. 보고서 작성 중 경계 시각을 넘기는 경우 서버가 기존에 승인한 예약 작업을 일관되게 완료/복구한다.

**B. 1회형 무료 체험권**
- 유효기간 내 **새 AI 보고서 1건의 생성권**을 부여한다. 유효기간(예: 발급/등록 후 30일)은 운영자 설정.
- 새 보고서 생성이 **정상 완료**될 때 1회를 사용한 것으로 확정한다. 생성 실패/시간 초과/취소는 예약을 해제하고 재시도할 수 있도록 한다. 중복 요청으로 2회 생성/차감되지 않도록 한다.
- 동일 보고서의 AI 수정 요청은 별도 보고서로 세지 않고, **수정 가능 횟수·시간·비용 한도**를 별도 설정한다. 구체적인 기본값(예: 수정 2회, 생성 후 24시간)은 출시 전 확정할 운영 파라미터이며 현재 미확정이다.

### 11.3 출시 단계 및 운영 모드

| 운영 모드 | 적용 시기 | 신규 보고서 생성 접근 |
|---|---|---|
| `PREOPEN_LIMITED` | 프리 오픈·품질 실증 | 관리자 지정 체험 그룹/체험권 지급 또는 제한된 공개 체험 정책의 유효 이용권 보유자 |
| `COUPON_ONLY` | 이벤트·쿠폰 배포 | 쿠폰 등록으로 획득한 유효 체험권 또는 프리미엄 이용권 보유자 |
| `PREMIUM_ONLY` | 고도화·안정화 후 | 프리미엄 사용자. 단, 이미 발급해 유지하기로 약정한 체험권은 **설정된 조건에 따라 만료까지 인정하거나 사전 고지 후 별도 처리** |

- 운영 모드 전환은 **관리자만** 가능하며 변경 이력을 남긴다. 전환으로 신규 무제한 생성 권한이 발생하지 않아야 한다.
- **프리 오픈도 무제한 무료가 아니다:** 계정별 생성 횟수, 수정 횟수, 총 API 비용 예산, 동시 작업/속도 제한을 둔다.
- 정식 프리미엄 출시 이전에는 PG/구독 결제 통합을 필수 범위로 넣지 않는다. 프리미엄 상품 권한과 수동 부여 계약만 먼저 준비한다.

### 11.4 이벤트 쿠폰 사용 여정
1. 사용자는 무료 Google 로그인 상태에서 `AI 보고서` 화면 또는 `내 이용권` 화면으로 진입한다.
2. 이용권이 없으면 **무료 체험권 등록** / 프리미엄 서비스 준비 안내를 표시하며 새로운 AI 생성 호출은 시작하지 않는다.
3. 사용자가 쿠폰번호 입력 → 서버가 유효 캠페인, 미사용/사용 가능 횟수, 만료, 계정별 지급 제한을 원자적으로 검사한다.
4. 성공 시 기간형 또는 1회형 체험권이 계정에 귀속된다. UI에 **유효기간, 남은 새 보고서 생성 가능 수, 수정 정책**을 표시한다.
5. 보고서 작성 시 서버가 권한을 검증·사용량을 예약하고, 성공 시 확정, 실패 시 예약 해제한다.
6. 체험 만료·소진 후 기존 사용자 자료와 Google Docs는 유지되고 새 AI 생성은 제한된다. 직접 작성 메모·Google Docs 직접 편집은 무료로 계속 가능하다.

### 11.5 화면/관리 기능
- 사용자 화면: `내 이용권` 상태, 남은 횟수/기간, 쿠폰 입력·등록 결과, 보고서 생성 가능 여부, 생성 시 차감 안내, 만료 후 업그레이드 안내.
- 관리자: 프리 오픈 모드, 쿠폰 캠페인 생성·중지·만료, **기간형/1회형 지정**, 발급 수량, 1계정 1회 등록 정책, 쿠폰 회수, 수동 부여, 체험 이용/실패/복구 집계, 비용 상한.
- 쿠폰 번호 추측 대입 및 중복 재사용 방지, 발급·사용 감사 로그, 개인정보와 원본 보고서 내용의 관리자 노출 제한.
- 체험권은 사용자 Google Sheets가 아닌 **Supabase 운영 DB**에만 저장한다. 이는 개인 수집 자료가 아니라 서비스 이용 권한·비용 정산 상태이기 때문이다.

### 11.6 사용자에게 전달할 메시지
- 무료 기능: **지도·기업 검색·현장 사진·녹음·메모·개인 저장·기존 자료 조회**.
- 프리미엄 기능: **개인 수집 자료와 승인된 공식 정보에 근거한 목적별 AI 보고서 신규 생성 및 AI 수정**.
- 단순한 Docs 열람·직접 편집을 유료 기능으로 되돌리지 않는다.

## 13. 성공 지표 및 수락 기준
- 지도 터치로 올바른 `exhibitor_id`의 기업 카드가 **지도 바로 아래**에 표시된다. 잘못된 매핑 0건(검증한 표본).
- iPhone 화면에서 2축 스크롤로 부스를 읽을 수 있고, 선택 영역은 이미지 스크롤 위치와 일치한다.
- 아이콘 순서가 **스피커 / 카메라 / 마이크 / A**이며 각 버튼의 실제 동작이 분명하다.
- 메모 창 열기/닫기/취소/저장/수정, 기업 연결 및 Sheets 반영이 테스트를 통과한다.
- 원본 미디어 누락 0건을 목표로 하되, 브라우저 저장소 제약과 실제 테스트 결과를 구분해 보고한다.
- 참가기업 목록/상세 필드 매핑·중복·검수·승인·출처/수집 일시를 기록하며 미승인 원문이 공개되지 않는다.
- 보고서 분석 방향·AI 수정·직접 편집·Google Docs 출력 요구가 유지된다.
- 일반 무료 사용자로 신규 보고서 생성 API가 실행되지 않으며, **유효 기간형/1회형 체험 사용자와 프리미엄 사용자만** 정책 한도 내 실행된다.
- 쿠폰 중복 등록·동시 생성 요청·API 실패 때 이용권이 잘못 소진되지 않으며, 만료 후 기존 보고서 열람·직접 편집이 가능하다.
- 외부 사용자 A/B 개인 Sheets/Drive 파일이 서로 접근 불가능하다.

## 14. 리스크 및 제외 범위
- **지도 사진 품질/권한:** 제공된 이미지가 저해상도라 확대 시 읽기 어렵고, 원본 공개/재배포 권한 미확인. 고해상도 공식 도면 또는 제공 허가 자료 확보 권장. 원본 부스번호와 상세 페이지의 부스번호 불일치 가능성 별도 검증.
- **잘못된 시각적 사실:** 과거 UI 콘셉트 그림의 가상 회사/좌표 사용 금지. 실제 지도는 사용자 제공 원본 기반.
- **외부 사이트 콘텐츠 권리:** 공개 페이지 수집 가능성과 재게시 권한은 별도. 공식 주최측 협의·이용 약관 검토, 이미지/원문 권한 확인, 미확인 시 원문 링크·사실 필드 중심.
- **iOS 제한:** 화면 잠금/백그라운드 녹음 완전 보장 불가. 중단 감지·기기 폴백 안내.
- **네트워크:** Drive/Sheets OAuth 재인증, API 할당량, 파일 누락/중복, 수동 수정 충돌에 대비.
- **프리미엄 출시·비용:** 체험 운영 조건 및 유료 상품 가격·PG 심사는 아직 확정되지 않음. 유료 결제 연결을 필수 P0 범위로 강제하지 않는다.
- **현장 일정:** 239개 전부 지도 클릭 좌표 보장, 자동 좌표 인식, 실시간 기업 정보 완전 재수집은 10/23 P0의 필수 완료 조건에서 제외하되, 개발 백로그/확장 범위에는 명시.
- **명시적 제외:** 자동 무단 녹음, 백그라운드 항시녹음, 위치 자동 추정으로 기업 변경, 사용자의 동의 없는 개인 자료 공개.

## 15. 추진 순서 및 승인 포인트
1. **Phase 0 감사:** 기존 Next.js/Prisma/SQLite/FieldDay·자료수집함·Report 코드/테스트 및 백업·작업 브랜치 파악.
2. **법적/원천 검토:** 행사 주최 측 CSV 제공 및 정보·로고·배치도 재사용 허용 범위 확인.
3. **Importer 5사 PoC:** 페이지 탐색, 상세 필드, 출처 저장, 누락·중복·오류 검증. 실제 공개 DB 발행 전 관리자 승인.
4. **Supabase 공용 카탈로그·RLS:** 기업/행사/참가/출처/검수·지도 데이터 타입과 변경 모델 확정.
5. **지도+4아이콘 P0:** 실제 이미지 로딩, 스크롤/선택, 기업 카드, 사진/녹음/메모 저장 및 도슨트.
6. **iPhone 현장 리허설:** LTE/불안정 네트워크/이어폰/복구, 10/22 목표 코드 동결.
7. **권한/체험 게이트:** 4가지 사용자 상태·기간형/1회형 쿠폰/동시 사용량 보호 설계·모의 테스트. 외부 베타 전 서버 이용권 검증 필수.
8. **별도 보고서·베타 출시 게이트:** 개인 데이터 기반 보고서 통합, 무료/체험/프리미엄 접근제어 및 외부 사용자 격리/피드백/비용 승인.
