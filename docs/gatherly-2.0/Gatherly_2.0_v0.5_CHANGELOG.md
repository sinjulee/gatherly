# Gatherly 2.0 v0.5 — 변경 이력 · 문서 정합성 확인

- **개정일:** 2026-10-16
- **기준:** v0.4의 Voice-First, 지도+기업 카드 4아이콘, 공식 디렉토리 Importer, Google 소유 데이터·Supabase 공식 DB를 **그대로 유지**.
- **이번 요청:** 사용자 유형 단순화 + AI 보고서 프리미엄 수익화 + 초기 프리 오픈/이벤트 쿠폰.
- **상태:** 문서 개정 완료, 실제 Gatherly 저장소·운영 DB 변경 없음.

## 1. 주요 결정

1. 화면상 사용자 4유형: **일반 무료 사용자 / 무료 체험 사용자 / 프리미엄 사용자 / 관리자**. 이전에 제안한 조직/프로젝트 전용 타입은 더 이상 사용자 타입으로 취급하지 않는다.
2. **체험권 유형은 2개만:** 기간형(`PERIOD`) 또는 1회형(`ONE_TIME`). 기간형의 생성 상한은 관리자 설정, 1회형은 신규 보고서 성공 시 1회 차감.
3. 운영 모드 `PREOPEN_LIMITED`, `COUPON_ONLY`, `PREMIUM_ONLY`에 따라 프리 오픈 → 이벤트 쿠폰 → 유료 프리미엄 전용 전환.
4. AI 보고서 자체의 필수 기능: 분석방향 지정, 근거·외부 조사, AI 초안, AI 수정, 직접 편집, Google Docs 출력 **유지**.
5. 보고서 **신규 생성·AI 수정 요청**에 서버 이용권 게이트 적용; 개인 현장조사·개인 Sheets/Drive·기존 Docs 조회/직접 편집은 무료로 유지.
6. Supabase는 관리자 역할·프리미엄/체험권·쿠폰·사용량·운영 정책을 보관. 개인 원본/보고서 본문은 개인 Google 저장소에 둔다.
7. 이용권 사용은 원자 예약→성공 확정/실패 복구, 요청 중복방지·쿠폰 일회성/재사용 정책을 서버에서 강제.
8. PG 결제·정기구독 연동은 **현재 구현 범위 제외**, 향후 프리미엄 정식 출시 전 별도 결정.

## 3. 아직 확정되지 않은 운영 정책
- 기간형 기본 제공 일수/보고서 신규 생성 상한, 1회형 지급/등록 유효기간.
- 1회형 포함 AI 수정 허용 횟수 및 허용 기간, 생성 중 경계 시각 처리.
- 이벤트 계정별 등록 횟수, 쿠폰 발급 방식/배포 채널, 할인 여부(현재는 무료 체험만 합의).
- `PREMIUM_ONLY` 전환 때 기존 체험 잔여 권리의 유예·고지 정책.
- 정식 상품 가격/구독 또는 건별 과금 방식/PG 제공사.

## 4. 안전한 개발 착수 게이트
- 맥미니 로컬 저장소 상태·기존 DB·기존 보고서 구현 상태는 아직 직접 확인하지 않았다.
- 사전 사용자 승인 없이 DB 실스키마 변경, 외부 데이터 일괄 수집/게시, 운영 OAuth, 배포, commit/push 금지.
- **초기 필수 검증:** AT-ACC-01~10 + 기존 지도/수집/보고서 회귀 테스트.

## 5. 이미지/외부 원천
- `v0.5_assets`에는 제목 없는 실제 부스배치도 참고본 및 모바일 UI 목업을 첨부.
- UI 목업의 업체/부스 텍스트는 **실제 공식 데이터로 사용하지 않음**.
- 원본 배치도·기업 소개·로고 공개 재사용 권리는 별도 확인.
